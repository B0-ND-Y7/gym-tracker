Gym Tracker v11.3

This is a UI/logic update. Keep your existing exercise-library.json, prep-library.json, images/ and videos/ in ~/gym-tracker.

Changes:
- Dynamic prep Randomise now changes the actual movement selection, not just their order.
- Adds extra text-only dynamic prep options when no suitable GIF exists.
- Reset & new workout avoids the current exercise list wherever alternatives exist.
- Fresh start clears all Gym Tracker local data on the device/browser running the app.
- Version is visible in the app header so you can confirm the live build.

No exercise-library rebuild is required for v11.3.
