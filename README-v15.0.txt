Gym Tracker v15.0.0

This is a clean workout-system rebuild.

Highlights:
- Push / Legs 1 / Pull / Legs 2 rotation
- Interactive Body Muscles SVG map
- Muscle-first exercise selection
- 3-column exercise grid on phone
- Local exercise GIF/JPG assets are used from the existing library
- Exercise notes stored per exercise
- Avoid/favourite exercise preferences
- One 90-second rest timer
- Local workout history and bodyweight tracking
- No stretch/prep system in this version
- Existing localStorage data is not migrated intentionally

The app expects these existing files at repository root:
exercise-library.json
videos/
images/

The Body Muscles visualisation is loaded from the published body-muscles UMD build. The library is Apache 2.0 licensed.
