Gym Tracker v11.2

Changes from v11.1:
- Added a Randomise button to Dynamic Prep. It keeps prep relevant to the current workout but chooses another suitable mix where available.
- Settings now has Reset & new workout for the current unsaved session.
- Reset clears all current set entries, rest timer, session duration and prep selection, then generates a genuinely different full workout for the same split.
- Reset is disabled for a workout that is already saved, to protect workout history.

This update does not include exercise-library.json, prep-library.json, images/ or videos/. Keep the generated library and media already in your gym-tracker repository.
