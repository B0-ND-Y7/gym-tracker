Gym Tracker v11

Main changes:
- New compact Home / Workout / Progress / More layout designed for iPhone.
- Automatic next-weight recommendation. When an exercise returns, the suggested weight is pre-filled. If every working set reached the top of the rep range last time, the suggestion increases by 2.5 kg, or 5 kg for larger lower-body movements. Tap Edit if the machine needs a different increment.
- Exercise preferences: Favourite, Avoid, and Not at my gym. Avoided/unavailable exercises are excluded from future selections; favourites are slightly more likely to return.
- Simple post-workout summary: duration, exercises, completed sets, new PBs, improvements from last time, and the next split.
- Fixed 2:00 automatic rest timer remains unchanged.
- 106-exercise rolling library, weekly variation, prep, stretches, GIF viewer, progress, history, body-weight tracking and backup remain.
- Existing exercise-library.json, prep-library.json, videos/ and images/ are not included in this update and will not be overwritten.

Install over the existing project. You do not need to rebuild the exercise library for this UI update.
